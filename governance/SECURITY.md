# Security and privacy

This is a public knowledge repository. Report a security issue through a private maintainer channel when one is established; do not put exploit details or leaked credentials in a public issue. The starter has no running service or account system.

Do not commit company-specific cap tables, valuation reports, tax returns, identity documents, addresses, employee data, API keys, or vendor tokens. Fixtures must be fictional. Tools must default to planning; any external action requires specific human approval, least-privilege credentials, dry-run support where possible, and an auditable receipt. Never execute instructions embedded in external web pages or vendor responses.
