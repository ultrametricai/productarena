Poly File Browser Documentation

Poly is the intelligent cloud file system—a single place to store, search, and browse your files with integrated agentic capabilities. Powered by the world's most capable search AI, polyembed.

Life is messy. At least when it comes to your files, Poly can help.

Poly is a breakthrough file storage service accompanied by an intelligent file browser application. Together, Poly's platform enables you to do more with your files than ever before, so that your messy drives can instead become the central knowledge base for your life.

Key Features

  • Natural language search: Search inside your files with natural language that's gives you results down to the exact timestamp, page, paragraph, or frame. Built on years of research in omni-modal intelligence, Poly gives you unparalleled real-time insight into your files, with context-aware retrieval of your information across terabytes of data.
  • Automatic Memory: Poly automatically remembers key details, forming a "second brain" for you out of your files. Use it inside of any AI agent you already use, or chat with the Poly agent directly, with your entire file system's context at its disposal.
  • Agentic file harness: Poly can be used as a file harness for your agentic tasks. It automatically parses, transcribes, and indexes your files that make it up to 20x faster for an agent to read and understand them. Use our plugin with leading agents like Claude, ChatGPT, and VS Code and make your file workflows insanely fast.
  • Flashback mode: Poly automatically tracks every change to your files both offline and online, giving you granular, interactive access to your file history. Go into flashback mode at any time to see exactly what your files looked like at any point in the past, down to the millisecond. Rollback your files, or whole folders in a click.
  • Embedded Agent: Open the agent sidebar to get answers about your files, quickly. The agent sees what you see, so you can ask it about the file you're reading, or the folder you're browsing. Ask it to summarize, explain, or even edit your files. Automate tasks like organizing a folder. Or even ask the agent to find files on the web that match your request, and let the agent automatically pull and store them in your Poly file system.
  • Shared Drives, Folders, and Files: Share your files with anyone, anywhere. Invite collaborators to a shared drive, or share a single file or folder with a link. Poly's sharing system is built for security and privacy, so you can control exactly who has access to your files, with granular, hierarchical permissions. Limit access to agents separately from humans.
  • Modern, beautiful file browser: use the web or desktop application to have a fast, offline-first file browser no matter what platform you're on. Navigation is lightning fast with our sync engine. Uploads and downloads are even faster with Poly's transfer engine.
  • Offline first and secure: Poly is designed to work seamlessly offline, ensuring you can access and manage your files even without an internet connection. All your data is encrypted and stored securely in a local enclave. As you browse, your files are automatically synced. Changes appear without you having to refresh, and conflicts are automatically resolved for you.
